## About

I'm the founder of **[SORAEN](https://soraenai.netlify.app)**, an AI research lab building language models people can trust.
Most assistants sound confident even when they're wrong. Ours answer from evidence, cite the source behind every claim,
and say *"I don't know"* instead of guessing.

## How I work

| | |
|:--|:--|
| **Evidence over guesswork** | A correct "the documents don't say" beats a fluent guess. |
| **Honest evaluation** | Decontaminated benchmarks, results published, losses included. |
| **Safety before shipping** | A model ships only if it is not less safe than its base. |
| **Open by default** | Weights, model cards and evaluation methods are public. |
